## 2. 라이브러리 배포하기

### 2.1. npm 회원가입하기

[npm | Home](https://www.npmjs.com/)에 접속하여 회원가입을 진행합니다.

![npm 홈페이지](/images/front-end/pnpm-tsdown-react-library-part-4/pic1.avif)

![npm 회원가입](/images/front-end/pnpm-tsdown-react-library-part-4/pic2.avif)

### 2.2. npm 로그인하기

다음 명령어를 입력하여 npm에 로그인합니다.

```bash
npm login
```

### 2.3. npm에 배포하기

배포하려는 라이브러리 패키지에서 다음 명령어를 입력하여 npm에 라이브러리를 배포합니다.

```bash
npm publish --access public
```

`--access public` 옵션은 공개 패키지를 배포할 때 사용합니다. 이 옵션을 생략하면 기본적으로 개인 패키지로 배포됩니다.
